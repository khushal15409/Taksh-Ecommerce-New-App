# Address Sync Implementation

This document describes the address synchronization implementation that integrates with the Taksh API and local Hive storage.

## Overview

The address feature now supports:
- ✅ Syncing addresses with the remote server
- ✅ Local caching using Hive database
- ✅ Offline support (reads from cache when offline)
- ✅ Automatic cache updates on successful API calls
- ✅ Full CRUD operations (Create, Read, Update, Delete)

## Architecture

The implementation follows Clean Architecture principles with three layers:

### 1. Data Layer

#### Remote Data Source
**File**: [`lib/features/address/data/datasources/address_remote_datasource.dart`](data/datasources/address_remote_datasource.dart)

Handles all API communication:
- `addAddress()` - POST to `/address/add` (returns 201 with no body)
- `getAddresses()` - GET from `/address`
- `updateAddress()` - PUT to `/address/{id}`
- `deleteAddress()` - DELETE to `/address/{id}`
- `setDefaultAddress()` - PUT to `/address/{id}/default`

**API Request Format** (for add/update):
```dart
{
  'state_id': '1',        // TODO: Get from location service
  'city_id': '1',         // TODO: Get from location service
  'area_id': '1',         // TODO: Get from location service
  'name': 'Home',         // Address label/name
  'mobile': '9722721834', // TODO: Get from user profile
  'address_line_1': '123, ABC Street',
  'address_line_2': 'Near Park',  // Optional
  'landmark': 'Blue Building',     // Optional
  'pincode': '380009',
  'is_default': '1'       // '1' for true, '0' for false
}
```

#### Local Data Source
**File**: [`lib/features/address/data/datasources/address_local_datasource.dart`](data/datasources/address_local_datasource.dart)

Manages Hive database operations:
- `getAddresses()` - Retrieve all addresses from Hive
- `saveAddresses()` - Save/replace all addresses in Hive
- `addAddress()` - Add a single address to Hive
- `updateAddress()` - Update an address in Hive
- `deleteAddress()` - Delete an address from Hive
- `clearAddresses()` - Clear all addresses from Hive

**Hive Box**: `addresses` (TypeId: 1 for AddressModel, TypeId: 2 for LocationModel)

#### Repository Implementation
**File**: [`lib/features/address/data/repositories/address_repository_impl.dart`](data/repositories/address_repository_impl.dart)

Coordinates between remote and local data sources:

**Sync Strategy**:
1. **Add Address**: 
   - Sends to remote API
   - On success, saves to local Hive
   - Returns the created address

2. **Get Addresses**:
   - If online: Fetches from remote, caches locally
   - If offline: Returns cached data
   - On network error: Falls back to cache

3. **Update Address**:
   - Updates on remote API
   - On success, updates local cache
   - Returns updated address

4. **Delete Address**:
   - Deletes from remote API
   - On success, removes from local cache

5. **Set Default**:
   - Updates on remote API
   - On success, updates all addresses in cache (unsets old default, sets new)

### 2. Domain Layer

#### Entities
**File**: [`lib/features/address/domain/entities/address.dart`](domain/entities/address.dart)

Core address entity with properties:
- `id`, `userId`, `type`, `customLabel`

- `addressLine1`, `addressLine2`, `landmark`, `instructions`

#### Use Cases

- [`DeleteAddress`](domain/usecases/delete_address.dart) - Delete address

#### BLoC

## Usage Example

### Adding an Address

```dart
import 'package:flutter_bloc/flutter_bloc.dart';
import 'package:taksh_e_commerce/features/address/domain/entities/address.dart';
import 'package:taksh_e_commerce/features/address/domain/entities/address_type.dart';
import 'package:taksh_e_commerce/features/address/domain/entities/location.dart';
import 'package:taksh_e_commerce/features/address/presentation/bloc/address_bloc.dart';

// In your widget
final addressBloc = context.read<AddressBloc>();

// Create a new address
final newAddress = Address(
  id: '', // Will be generated by repository
  userId: 'user_123',
  type: AddressType.home,
  customLabel: 'My Home',
  location: Location(
    latitude: 23.0225,
    longitude: 72.5714,
    formattedAddress: 'Ahmedabad, Gujarat',
    city: 'Ahmedabad',
    state: 'Gujarat',
    country: 'India',
    postalCode: '380009',
  ),
  addressLine1: '123, ABC Street',
  addressLine2: 'Near Park',
  landmark: 'Blue Building',
  isDefault: true,
  createdAt: DateTime.now(),
  updatedAt: DateTime.now(),
);

// Add the address
addressBloc.add(AddAddressEvent(newAddress));

// Listen to state changes
BlocListener<AddressBloc, AddressState>(
  listener: (context, state) {
    if (state is AddressAdded) {
      // Address added successfully
      print('Address added: ${state.address.id}');
    } else if (state is AddressError) {
      // Error occurred
      print('Error: ${state.message}');
    }
  },
  child: YourWidget(),
)
```

### Fetching Addresses

```dart
// Load addresses
addressBloc.add(LoadAddresses());

// Display addresses
BlocBuilder<AddressBloc, AddressState>(
  builder: (context, state) {
    if (state is AddressLoading) {
      return CircularProgressIndicator();
    } else if (state is AddressesLoaded) {
      return ListView.builder(
        itemCount: state.addresses.length,
        itemBuilder: (context, index) {
          final address = state.addresses[index];
          return ListTile(
            title: Text(address.displayLabel),
            subtitle: Text(address.fullAddress),
            trailing: address.isDefault 
              ? Icon(Icons.check_circle, color: Colors.green)
              : null,
          );
        },
      );
    } else if (state is AddressError) {
      return Text('Error: ${state.message}');
    }
    return SizedBox.shrink();
  },
)
```

## Data Flow

### Adding an Address

```
UI (AddAddressPage)
  ↓ AddAddressEvent
AddressBloc
  ↓ call()
AddAddress UseCase
  ↓ addAddress()
AddressRepository
  ↓
  ├─→ AddressRemoteDataSource.addAddress()
  │     ↓ POST /address/add
  │   API Server (returns 201)
  │
  └─→ AddressLocalDataSource.addAddress()
        ↓ put()
      Hive Database
```

### Getting Addresses (Online)

```
UI
  ↓ LoadAddresses
AddressBloc
  ↓ call()
GetAddresses UseCase
  ↓ getAddresses()
AddressRepository
  ↓ Check network
  ├─→ [Online] AddressRemoteDataSource.getAddresses()
  │     ↓ GET /address
  │   API Server
  │     ↓ addresses
  │   AddressLocalDataSource.saveAddresses()
  │     ↓ clear() + put()
  │   Hive Database (cache updated)
  │
  └─→ [Offline] AddressLocalDataSource.getAddresses()
        ↓ values.toList()
      Hive Database (cached data)
```

## Troubleshooting

### Address not syncing
1. Check network connectivity
2. Verify API endpoint is correct
3. Check authentication token is valid
4. Review logs for error messages

### Hive errors
1. Ensure Hive is initialized in `main.dart`
2. Verify type adapters are registered
3. Check box is opened before use

### API returns 401
- Authentication token expired or invalid
- Re-login required

### API returns 422
- Validation error
- Check required fields are provided
- Verify field formats match API expectations
